# Sightline releases

Installers for Sightline, game streaming for a group of friends: Discord's delay with a picture
close to the source. The streamer runs a small tray app; friends watch in a browser tab.

**[Download the latest installer for Windows](https://github.com/DeadKernel/sightline-releases/releases/latest/download/Sightline-setup.exe)**

- Windows 10 or 11, 64-bit. Installs for your user only, no admin prompt.
- Windows may say "Windows protected your PC" the first time, because the installer isn't
  code-signed yet: More info → Run anyway.
- Once installed, Sightline updates itself: when a new version is out, Settings shows
  "Restart to update". It never updates while you're live.
- Watching needs nothing installed: open the link the streamer shares.

This repo only holds release files; the source is private.
